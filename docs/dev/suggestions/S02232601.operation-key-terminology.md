### S02232601 Standardize operation key terminology

Public docs, Javadocs, and exception messages alternate between "op", "op key", "op name", and
"operation key". Standardize on "operation key" (with "op" used only in variable names) across
public-facing text so terminology reads consistently and error messages align with the docs.

- Replace "op name" and "op key" phrasing in public docs/Javadocs with "operation key".
- Align exception messages that mention "op" to say "operation key" where user-facing.
- Update Troubleshooting section titles/anchors if needed to keep the terminology consistent.
