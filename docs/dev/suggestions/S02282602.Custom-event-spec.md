### S02282602 Specify custom event registration and semantics

The specification leaves "Configuring Custom Events" empty, while code hints at event type registration and
runtime splitting. This makes it unclear how users define new events, how those events are matched to rules,
and whether custom events participate in split evaluation or intent checks. Make custom events a first-class
spec item so end users can safely extend the event system.

- Document how custom events are declared or registered (API and configuration points).
- Specify how a custom event maps to TypeKey and EventKey, including collision and naming rules.
- Clarify whether custom events are split into derived events, and how they participate in intents.
- Define the error behavior for unregistered or unsupported custom event types.
