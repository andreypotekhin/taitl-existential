### S03012601 Avoid merge-conflict artifacts
Introduce an automated check (CI or pre-commit) that fails builds when merge-conflict markers appear in the
codebase or documentation. This prevents broken builds and public docs that still contain conflict markers.

- Add a small script (e.g. rg "<<<<<<<|>>>>>>>|=======") wired into the build or CI pipeline.
- Exclude vendor/third-party directories if needed.
- Document the check in /docs/dev/Development.md or /docs/dev/Setup.md.
