### S02222615 Document concurrency guarantees for configuration and injection

The library exposes configuration, event registration, and injection APIs that can be called from multi-threaded
applications. Suggest adding a short, explicit "Concurrency guarantees" section to Readme.md and
/docs/dev/Specification.md that clarifies what is thread-safe, what must be done during single-threaded
configuration, and which APIs (e.g., Creator.inject, EventMask.registerEventType) should be called before
transactions begin.

- Add a public-facing summary in Readme.md.
- Add a more detailed developer note in /docs/dev/Specification.md.
- Include examples of safe ordering for configuration vs runtime usage.
