## Implement EvaluationLogic.evaluate()

Implement EvaluationLogic.evaluate():

Iterate over events from EncounteredUniqueEvents index
Split Event into elementary events (a RuntimeKey into a set of RuntimeKeys)
Create a MultiKey from the above
Retrieve event handlers (from EventField)
Iterate over event handlers
Execute handler
Write constraint violations to ValidationReport
Throw on other exceptions from handlers
Returning incomplete ValidationReport is ok
