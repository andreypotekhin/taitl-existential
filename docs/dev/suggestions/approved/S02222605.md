### S02222605 Key Naming Strategy Injection

Introduce a user-configurable strategy for building TypeKey and EventKey strings, defaulting to the current
simple-name behavior but allowing fully-qualified naming or custom policies. This enables safe extensibility
when multiple libraries define overlapping class names or when custom events share names across packages.

- Add a KeyNamingStrategy interface with defaults for short-name and full-name generation.
- Allow Creator injection for the strategy, and thread it through TypeKey/EventKey factories.
- Document usage in Readme and Specification.md with examples and migration notes.
