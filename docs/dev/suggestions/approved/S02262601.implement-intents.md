### S02262601 Implement intents

Implement Intents section of the Specification.

Implement Intent class, similar to Invariant class.
Add intents to configuration flows (Intent, IntentBuilder) similarly
to how Invariant is wired in.
Allow for these event handlers in Intent: read(), write(), change(), update() etc.

Example code:
 intent(new Intent<Pilot>() {{
    read(); // Allow reading from Pilots table, unrestricted
    update(p -> p.equals(curPilot)); // Allow changing Pilots table, only for one specific pilot
    write(p -> writeCount == 0 && ++writeCount); // Allow writing only once
}})
