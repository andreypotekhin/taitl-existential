### S02222614 Child context builder support

Context and ContextBuilder both include TODOs to support building child contexts, but the fluent API cannot
attach child contexts today. This limits extensibility for hierarchical operations (e.g. "/api" -> "/api/cats"
-> "/api/cats/create") when configuration is expressed in nested modules.

- Add `ContextBuilder.context(String name)` to create and attach child
  contexts to the current context, not just to the root ConfigBuilder.
- Ensure child contexts inherit factories and parent pointers, and document the precedence/ordering rules.
- Add a spec test showing a child context defined from a parent builder being included in the config.
