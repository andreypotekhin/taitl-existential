### S03012601 Transaction helper for safe commit/rollback

End users routinely need to wrap a transaction in begin/commit/rollback handling, which is error-prone and
creates a large amount of boilerplate. Add a small public helper API that executes a user action within a
transaction boundary, auto-committing on success and rolling back on failure, and always surfacing the
original exception.

- Add a public helper in `Ex` and `Existential` (for example `withTransaction(op, action)`), taking a
  lambda/functional interface to execute.
- Ensure rollback runs on any failure (including unchecked exceptions) and that the original exception
  is rethrown without being masked by rollback failures (attach rollback failures as suppressed).
- Document the helper in /docs/Usage.md with a concise example alongside the manual pattern.
