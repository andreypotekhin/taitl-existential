### S02242601 Allow creating constraints with type key

Currently, when creating invariants, effects, and lives, we can only specify 
the constraint Class<T> parameter. This limits our ability to create constraints for generic types.
To address this, add ability to create Invariants, Effects, Lives with TypeKey<T> parameter.
- Add TypeKey field to Invariant, Effect, Life
- Allow to specify TypeKey when creating instances of these classes
- Allow to specify TypeKey in constructors of builders for these classes
- Allow to specify TypeKey when building these classes with parent builders

Example: 
We have: ContextBuilder.invariant(Class<T> cls)
We want to add: ContextBuilder.invariant(TypeKey<T> typeKey)
