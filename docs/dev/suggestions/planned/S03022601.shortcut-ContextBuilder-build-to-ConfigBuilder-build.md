### S03022601 Shortcut ContextBuilder.build to ConfigBuilder.build

On ConfigBuilder, we can build several contexts by successfully calling .context()
But, when we have a build() call in the end of call chain, it only builds the last context.
We want to refactor that to: 
1) make ContextBuilder.build() effectively a call to ConfigBuilder.build()
2) make ConfigBuilder.build() (without parameters) to build the instances of all defined Contexts and Transactions
