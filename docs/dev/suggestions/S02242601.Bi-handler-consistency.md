### S02242601 Bi-handler constraint consistency

OnMutate and OnPort duplicate conditional handling and currently rely on ad-hoc exception choices.
Extract shared constraint evaluation for bi-event handlers so both classes use a single, explicit
policy for condition evaluation, condition-missed exceptions, and description formatting.

- Introduce a shared helper or abstract base for bi-event handlers that encapsulates
  condition/bicondition validation, constraint-only flow, and error shaping.
- Align condition-missed failures on a dedicated exception (or documented EventHandlerExecutionException),
  and document the behavior in Javadoc.
- Add focused tests that assert identical behavior for OnMutate and OnPort when used as constraints.
