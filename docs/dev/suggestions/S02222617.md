### S02222617 Cross-platform secure config permission checks

Configuration file hardening currently relies on POSIX permissions and skips checks on non-POSIX file systems.
Add an ACL-based verifier (AclFileAttributeView) for Windows/NTFS to ensure the config file is owned by the
current user and not writable by broad principals (e.g., Everyone, Authenticated Users). This closes a gap on
Windows while keeping behavior consistent with the existing POSIX rules.

- Add a FileSecurity ACL helper that inspects owner and write permissions for common broad principals.
- Wire ConfigureLibrary to call the ACL helper when POSIX attributes are unavailable.
- Add unit tests that validate the ACL path using a mock FileSystem or guarded integration test.
