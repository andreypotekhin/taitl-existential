### S02222616 LimitedInputStream boundary validation

LimitedInputStream does not define behavior for negative limits or the zero-limit edge case, and the
exception message does not point to troubleshooting guidance. Clarify boundary behavior, fail fast on
invalid configuration, and add targeted tests so consumers can rely on deterministic limits handling.

- Validate `maxBytes` is non-negative in the constructor and throw IllegalArgumentException with a
  stable message when misconfigured.
- Add tests for `maxBytes == 0` (EOF vs overflow) and `maxBytes < 0`.
- Document the behavior and troubleshooting reference in the class Javadoc or exception message.
