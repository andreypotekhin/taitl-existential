### S02252601 Configuration integrity verification

Configuration hardening currently focuses on ownership, permissions, and file size. Add an optional integrity
check so operators can pin the exact configuration expected at runtime (for example, a SHA-256 digest or an
HMAC passed via an environment variable). This blocks silent tampering when files are stored on shared or
container-mounted volumes.

- Add a new configuration option (env or system property) for expected config digest.
- When set, compute the digest of the loaded configuration bytes and fail fast on mismatch.
- Document usage in Troubleshooting and Readme with a short example.
