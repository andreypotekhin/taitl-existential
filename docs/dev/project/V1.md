# V1: Library Configuration and Transaction Foundations

Status: planned; not released. Release labels retain the roadmap convention:
V1 denotes 0.0.1, not semantic-version major 1.
Dates and capacity are not assigned. Scope is unchanged from [Roadmap.md](Roadmap.md).

## User outcome

Configure operation-scoped rules and independent transactions, evaluate them at specified stages, and use the
existing public interfaces with predictable configuration, intent, indexing, and lifecycle behavior.

## Dependencies and risks

Events, basic invariant/effect execution, diagnostics, and ordinary transaction disposal are required to demonstrate
V1. Their broader V2 completion does not excuse a failing V1 prerequisite. Specify overlapping context order, stage
semantics, event identity, checkpoint behavior, and failure recovery before implementing affected changes.

## Exit criteria

- All V1 roadmap rows have passing requirement-level acceptance cases and documented limitations.
- The full clean Maven installation passes, required validation-report tests execute, and coverage checks have data.
- Examples remain test-only, diagnostics provide remedies, and comparable transaction benchmarks are reviewed.
- No release blocker remains; any proposed scope deferral requires an explicit roadmap/release decision.

## Release evidence and review
