# Milestones

A leading `+` marks an evidenced completed milestone. Dates are not assigned. See the
[backlog](Backlog.md), [release traceability](TraceabilityMatrix.md), and [assessment](Assessment.md).

+ M0: Documentation and planning foundation ready: process, topic designs/specifications, V1/V2 charters, epics,
  sprints, example extraction, and performance evidence established. This is not release completion.

M1: V1 library/configuration evidence complete (Sprints 01–02).
M2: V1 evaluation, intent/index, and lifecycle evidence complete (Sprints 03–04).
M3: V1 hardening exit criteria satisfied (Sprint 05); see [V1](V1.md#exit-criteria).
M4: V2 events, constraints, and relationship/quantifier evidence complete (Sprints 06–07).
M5: V2 effects, custom events, reporting, and housekeeping evidence complete (Sprints 08–09).
M6: V2 independent consumption and publication prerequisites/evidence complete (Sprint 10).
M7: V2 hardening exit criteria satisfied (Sprint 11); see [V2](V2.md#exit-criteria).

Record evidence links and the actual completion date when promoting a milestone. Do not mark a future sprint complete
because its charter or design document has been written.
