# Milestones

A leading `+` marks an evidenced completed planning milestone, not completion of a release feature.
[Rebaseline](ReleaseRebaseline.md) records the pivot from the archived initial scope to the current outcomes.

+ M0: Initial documentation-first foundation established; historical evidence is preserved in the assessment.
+ M1: Three-release capability planning and explicit design quality obligations established.

M2: V1 representative workflow, relationships/evolution, and recovery/resource acceptance complete (Sprints 01–03).
M3: Night City independent Maven consumption and representative performance evidence complete (Sprint 04).
M4: V1 hardening exit criteria satisfied (Sprint 05); see [V1](V1.md#exit-criteria).
M5: V2 standard configuration/context/type/stage/transaction breadth complete (Sprints 06–08).
M6: V2 maintained relationships and operational/resource breadth complete (Sprint 09).
M7: V2 hardening exit criteria satisfied (Sprint 10); see [V2](V2.md#exit-criteria).
M8: V3 custom-event registration/evaluation and extension evidence complete (Sprints 11–12).
M9: V3 hardening exit criteria satisfied (Sprint 13); see [V3](V3.md#exit-criteria).

Publication readiness/availability is tracked separately; a functional milestone does not imply remote publication.
Record actual completion dates, requirement/evidence links, and blockers before promoting a milestone.
