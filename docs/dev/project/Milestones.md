# Milestones

A leading `+` marks an evidenced completed planning milestone, not completion of a release feature.
[Rebaseline](ReleaseRebaseline.md) records the pivot from the archived initial scope to the current outcomes.

+ Initial documentation-first foundation established; historical evidence is preserved in the assessment.
+ Three-release capability planning and explicit design quality obligations established.

+ V1 representative workflow, relationships/evolution, recovery/resource acceptance, and independent Maven consumption
  complete on 2026-10-22 (Sprints 01–04); see [traceability](TraceabilityMatrix.md).
+ V1 hardening exit criteria satisfied and local 0.0.1 artifact installed on 2026-10-22 (Sprint 05); see [V1](V1.md#exit-criteria).
- V2 standard configuration/context/type/stage/transaction breadth complete (Sprints 06–08).
- V2 maintained relationships and operational/resource breadth complete (Sprint 09).
- V2 hardening exit criteria satisfied (Sprint 10); see [V2](V2.md#exit-criteria).
- V3 custom-event registration/evaluation and extension evidence complete (Sprints 11–12).
- V3 hardening exit criteria satisfied (Sprint 13); see [V3](V3.md#exit-criteria).

Publication readiness/availability is tracked separately; a functional milestone does not imply remote publication.
Record actual completion dates, requirement/evidence links, and blockers before promoting a milestone.
