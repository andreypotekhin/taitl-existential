# V2: Constraint Coverage and Distribution

Status: planned; not released. Release labels retain the roadmap convention:
V2 denotes 0.0.2, not semantic-version major 2.
Dates and capacity are not assigned. Scope is unchanged from [Roadmap.md](Roadmap.md).

## User outcome

Express the full admitted entity/relationship/evolution constraints, quantifiers, effects, and custom events; receive
useful violation reports and consume a resource-safe library through the documented Maven distribution path.

## Dependencies and risks

Retain V1 behavior while extending V2. Resolve custom-event registration/splitting, relationship-index semantics,
effect failure behavior, and resource/cache ownership in the paired topic designs. External publication needs
account/namespace/signing prerequisites; a local install is not proof of remote availability.

## Exit criteria

- All V2 and retained V1 acceptance cases pass with direct evidence for quantifiers, effects, custom events, and
  cleanup.
- Artifact contents and separate consumer execution match the documented Maven distribution claim.
- Full clean verification and actual coverage collection pass; required skips/unavailable evidence are resolved.
- Comparable performance/resource evidence is reviewed and no release blocker remains.
- Remote publication is verified before claiming remote dependency availability; otherwise release closure stays
  blocked.
