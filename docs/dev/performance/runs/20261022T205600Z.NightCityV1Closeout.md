## Environment and workload

Amazon Corretto 17.0.15+6-LTS, Maven 3.9.10, macOS 15.6.1 arm64, Apple M4, 10 online processors. No extra JVM
options. The consumer uses only the installed `0.0.1` library artifact. Each workload size includes that many unrelated
map rows plus the valid and rejected workflow rows. Configuration, source construction, JVM/Maven startup, and cleanup
are outside timing. Each path runs 50 warmups and 250 measured workflows. Transactions close in `finally`; scenarios
close their library and restore the prior facade instance.

## Reproduction

Run the following command three times from the repository root, as separate Maven invocations:

    mvn -f examples/night_city/pom.xml -Dbenchmark.warmup.iterations=50 -Dbenchmark.measure.iterations=250 -Dexec.mainClass=com.taitl.ex.examples.night_city.app.NightCityWorkflowBenchmark compile exec:java

Each invocation exited zero. Timed paths include successful creation/commit, rejected creation with explicit rollback,
rejection followed by rollback and a fresh successful transaction, and sixteen reads in one transaction. The source
sizes are 16, 256, and 4096 unrelated rows.
