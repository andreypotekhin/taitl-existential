Every validation success and recovery workflow observed exactly 10,000 validation callbacks after commit and none
during event reporting. Every immediate workflow observed exactly 10,000 immediate callbacks while reporting.

These small-workload samples are phase evidence, not directly comparable to the 10,000-entity baseline.
