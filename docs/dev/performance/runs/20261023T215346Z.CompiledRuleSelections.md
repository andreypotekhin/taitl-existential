## Measurement limits and reproduction

Allocation is current-thread ThreadMXBean bytes. The test-only agent sums instrumented shallow sizes over the
identity-deduplicated reachable graph; it excludes Class objects, static/ClassValue/JVM metadata, and weak referents.
This is not exclusive dominator retention, process heap, or proof of class-loader collection. Reachable graph counts
include shared configured callbacks; caller closures can retain caller data. See the [profiling
procedure](../Readme.md#reachable-memory-profiling) for the agent and module opens.

From the repository root, first run `mvn clean install`. Three independent invocations per sample use:

    mvn -o -q -f examples/night_city/pom.xml \
        -Dexec.mainClass=com.taitl.ex.examples.night_city.app.NightCityExecutionBenchmark \
        -Dbenchmark.entities=10000 -Dbenchmark.types=200 -Dbenchmark.rules=100 \
        -Dbenchmark.warmup.iterations=2 -Dbenchmark.measure.iterations=5 compile exec:java

For scale/immediate replace parameters with the values above. After attaching the test agent:

    mvn -o -q -Pbenchmarks -Dtest=MembershipRepresentationBenchmark \
        -Dbenchmark.types=200 -Dbenchmark.rules=256 -Dbenchmark.sample=1 \
        -Dbenchmark.warmup.iterations=50 -Dbenchmark.measure.iterations=500 \
        -Dbenchmark.heap.required=true test

Use sample=1,2,3 and rules=100,256,500. Bounds adds `-Dbenchmark.bounds=true`; stress uses types=20, rules=500, and
`-Dbenchmark.id.stride=256`. Cache profiles use:

    mvn -o -q -Pbenchmarks -Dtest=ExecutionPlanBenchmark \
        -Dbenchmark.types=200 -Dbenchmark.rules=100 \
        -Dbenchmark.warmup.iterations=3 -Dbenchmark.measure.iterations=5 \
        -Dbenchmark.heap.required=true test

Mixed replaces types=100/rules=256 and adds `-Dbenchmark.mixed=true`. Repeated adds entities=10000/reports=16. The
paired probes run via `java -cp` with the chosen library JAR, target/test-classes, AspectJ runtime/weaver 1.9.21 JARs,
and main class `com.taitl.existential.benchmarks.SelectionProbe` or `RejectionProbe`. No target/classes entry is
allowed; SelectionProbe uses the graph agent and required=true. Run each probe/library pair three times in alternating
baseline/candidate order. Archived baseline JAR digest and source hashes identify the measured dirty snapshot;
reproducing a historical dirty baseline requires those matching source contents, not only its checkout SHA.
