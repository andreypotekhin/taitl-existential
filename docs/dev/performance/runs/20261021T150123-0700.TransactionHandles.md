## Environment and workload

JDK: Amazon Corretto 17.0.15+6-LTS (64-bit Server VM); Maven 3.9.10. OS: macOS 15.6.1; architecture: arm64; Apple M4. Each independent Maven invocation started a fresh test JVM. The fixed scenario order was static-context, configured-transaction, custom-transaction. Each scenario used 5,000 warmup and 50,000 timed transactions. One thread updated one Cat per transaction; the timed portion included begin, one update, and commit. See the linked baseline for detailed workload boundaries and caveats.

## Reproduction

Run three times as separate invocations:

    mvn -q -Pbenchmarks -Dbenchmark.warmup.iterations=5000 -Dbenchmark.measure.iterations=50000 test

All three invocations exited zero and ran `CustomTransactionBenchmark`. Raw output was retained at `/tmp/taitl-handles-benchmark-after-{1,2,3}.log` during this session.
