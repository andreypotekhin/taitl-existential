## Three independent workflow samples

Each fresh Maven process used 10,000 entities, 200 distinct actual descriptors, 100 validation declarations, one
warmup, and three measured workflows. Fixture and configuration work was outside timing. Each success/recovery
workflow ran exactly 1,000,000 validation callbacks; each process reported exactly 8,000,000 callbacks across warmup
and measured runs. Rejection expected a validation failure and explicitly rolled the transaction back. All workflow
transactions and the library instance closed deterministically. Values are nanoseconds per complete workflow.

| Workflow | Sample 1 | Sample 2 | Sample 3 | Median | Range |
| --- | ---: | ---: | ---: | ---: | ---: |
| Success | 66,342,764 | 65,547,639 | 63,981,152 | 65,547,639 | 63,981,152–66,342,764 |
| Rejection with rollback | 1,047,847 | 1,072,652 | 1,109,638 | 1,072,652 | 1,047,847–1,109,638 |
| Rejection and recovery | 70,389,555 | 58,818,250 | 56,509,069 | 58,818,250 | 56,509,069–70,389,555 |

Run command, executed three times in separate Maven/JVM processes:

    mvn -q -f examples/night_city/pom.xml \
        -Dexec.mainClass=com.taitl.ex.examples.night_city.app.NightCityExecutionBenchmark \
        -Dbenchmark.entities=10000 -Dbenchmark.types=200 -Dbenchmark.rules=100 \
        -Dbenchmark.warmup.iterations=1 -Dbenchmark.measure.iterations=3 compile exec:java

## Scale and cardinality smokes

A one-sample 100,000-entity/200-descriptor/100-rule run completed: success 1,016,775,333 ns, rejection with rollback
5,001,916 ns, and recovery 649,036,333 ns. It observed 20,000,000 expected callbacks and closed its transactions and
instance. A separate 500-entity/200-descriptor/500-rule smoke completed with 500,000 expected callbacks; the success,
rejection, and recovery workflows reported 81,368,833 ns, 7,089,625 ns, and 27,333,917 ns respectively. These single
samples demonstrate fixture and runner coverage at the planned upper cardinalities; they are not comparative
performance evidence.

No allocation or retained-heap profile was collected. Setup/finalization and commit are not reported as separate
timings in this runner. These samples establish a reproducible complete-workflow baseline and do not establish a
throughput target or a numeric performance gate.
