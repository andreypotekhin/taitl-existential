Each scenario configures its `Existential`, dwelling map, and rules before timing. Each operation receives 50 warmup and

library after the workload and restores the previous `Ex` instance.

## Reproduction

Run three separate invocations from the repository root:

    mvn -f examples/night_city/pom.xml -Dbenchmark.warmup.iterations=50 -Dbenchmark.measure.iterations=250 -Dexec.mainClass=com.taitl.ex.examples.night_city.app.NightCityWorkflowBenchmark compile exec:java

All three invocations exited zero. The consumer resolved `com.taitl:existential:0.0.1-SNAPSHOT`; no root source or
class directory was on its compile path. Workload sizes were 16, 256, and 4096 unrelated rows, plus the two workflow
rows noted above. The raw output was retained in the task transcript.
