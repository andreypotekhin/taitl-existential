### T02262601 implement EvaluationLogic.evaluate()

Implement `EvaluationLogic.evaluate()` per approved suggestion `S02262601`:

- iterate over events from `EncounteredUniqueEvents`
- split each event into elementary events (`RuntimeKey` set)
- create `MultiKey`
- retrieve handlers from `EventField`
- execute handlers
- write constraint violations to `ValidationReport`
- throw on non-violation handler exceptions
- partial `ValidationReport` is acceptable when aborting on non-violation errors
