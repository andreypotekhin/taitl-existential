## Surprises & Discoveries

Final review separated the closed memo-query remedy from library shutdown: only a fresh transaction is required.
A direct test verifies the same library stays usable. This tiny unmeasured-branch wording correction and its test are
recorded separately from measured source hashes; all full builds were rerun afterward.

TypeKeyCache is a process-wide Creator singleton with unbounded strong Class keys. Other active caches already have
explicit budgets: 128 operation generations/execution plans, 1024 prepared selections, 64 warning signatures, and 4096
legacy descriptors with weak Class keys. CacheHandlers is an unused stub, not a cache used by transaction execution.
Existing operation/selection caches invalidate by owning configuration/inventory generation; hot reload is outside V2.

Standard events carry any typed application value. An envelope containing an entity, actor and requested destination
therefore needs no custom event registration or untyped metadata map. That gives the vague additional-values claim a
concrete V2 example while keeping V3 custom event splitting outside scope.

Supplied rule containers are borrowed, not cloned. Handlers/callbacks may be arbitrary subclasses and capture caller
state, so arbitrary deep copying is unsound. Settle the supported contract as read-only reuse after finalization, with
independent declaration provenance and prospective required-description checks when supplied sets are attached.

Full regression testing found that OnTransit/OnPort use the handler exception type for ordinary failed checks. The
standalone one-argument factory must assign RULE-REJECTED explicitly; assigning CALLBACK-FAILED merely from the class
would turn validation collection into an immediate failure. Equal explicit intent types preserve existing container
identity; only differing type bindings need a shallow leaf copy. Full-name envelope acceptance uses explicitly matching
TypeKeys, as required by the existing naming contract. Maintenance wrapping preserves the extractor in its existing
cause chain, rather than promising a direct cause. These findings are captured in the direct and retained V1 tests.

## Decision Log

On 2026-10-27, finish the admitted capabilities rather than treating old missing evidence as implementation. Use
ClassValue for inferred type metadata: two naming-mode values per runtime Class, no strong global Class-key map and no
instance close that invalidates another instance. Preserve actual Class identity and existing TypeKey identity reuse.
Explicitly owned configurations retain application definitions until their owners release them; library close drains
and clears its resident caches, while escaped caller definitions remain caller-owned. No GC timing claim is made.

Keep library exception constructors plain for caller-created failures. Extend library-generated MemoException,
maintenance and cleanup failures with detached snapshots. Keep exact Java IllegalStateException/IllegalArgumentException
catch types for configuration/lifecycle errors; give those errors stable code/remedy/troubleshooting text through a
shared failure-only renderer. Do not force them into the unrelated ExistentialException hierarchy. Programmer
preconditions (nulls, malformed method arguments), unsupported internal stubs and arbitrary caller exceptions retain
ordinary Java behavior; the public-error catalog describes library semantic failures, not every Java Throwable.
No shared Throwable registry or stack inspection may recover metadata. Rendering/decorating RuntimeException falls
back to the original text; Error propagates. Existing callback classification and cleanup/cause/suppressed order stay.

Supplied rules must be fully configured before first begin and remain unmodified after binding; reuse is supported
across contexts/instances when the definitions are read-only and callback state is appropriately synchronized. Required
description policy at attachment validates existing leaves without mutating the supplied rule's own option. Rejection
adds no registration; correcting the rule and retrying remains possible. No arbitrary callback snapshot is promised.

Ex.close closes the currently installed facade instance idempotently, without replacing it or closing independent
instances. Beginning again requires an explicitly created/installed instance. The test-only instance setter remains
explicit and does not implicitly close its previous instance. Global caches store metadata only, never reported values.
Remote publication readiness is a documented prerequisite checklist; no external publication is authorized or claimed.
