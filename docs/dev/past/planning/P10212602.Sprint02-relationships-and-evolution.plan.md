## Decision Log


Use plain caller-owned collections/maps for the V1 relationship. Add a ConfigureCats fixture method for a single
selected dwelling per cat and reuse the existing birth/state/evolution rules. All(new Exists(source)) composes as a
predicate; a conditional All can select cats needing the relationship. Missing/empty membership, absent/null mapped
dwellings, and location mismatch reject validation. A nonselected conditional subject skips the relationship.
Predicates that inspect a matched source value/key keep that source object, rather than substituting the reported
equal snapshot. Default membership-only Exists delegates to Collection.contains, Set.contains, or Map.containsKey;
it does not need the stored source object. These decisions keep the public API unchanged.

Transit requires both states; port admits creation/deletion by one null endpoint and rejects two null endpoints.
Relationship rules use the selected event entity under the dispatch contract: after-value when present, otherwise
before-value. Configuration is frozen at begin; caller-owned source contents can change between validation attempts
with appropriate application synchronization. Do not mutate hash keys while stored in source/runtime indexes.
Failed commit detaches the active registry entry; explicit rollback releases the handle and runs its callbacks.
Caller-owned objects/maps are neither maintained nor undone. Error output must identify operation and failed rules.

## Surprises & Discoveries


Existing Sprint 02 evidence already covers fluent dispatch, endpoint selection, and several creation/relocation cases.
It does not cover All-Exists composition or cardinality scaling. Default Exists currently wraps an always-true
predicate and still recovers the actual stored set value/map key by iteration; predicates that inspect that object
need the recovery, while pure membership does not.

Relationship acceptance also exposed that IndexData.close was empty and ConcreteTr.close never closed runtimeIndexes.
The selected workflow therefore retained event/entity references through a closed handle. Correct this narrow resource
bug in the same delivery and verify all three runtime index collections clear through a retained handle. Broader close
and failure cleanup remains Sprint 03. Event folding uses instance identity; equal snapshots are source-membership
matches but distinct reported entities. Tests repeat the same reported instance when asserting folding.

Maven Surefire's exact -Dtest=ExistsTest filter skipped nested tests and failed with zero executions. Use the quoted
wildcard '-Dtest=ExistsTest*' for the complete 13-case class, and inspect actual counts rather than assuming selection.
Full-suite discovery includes the nested cases normally.
