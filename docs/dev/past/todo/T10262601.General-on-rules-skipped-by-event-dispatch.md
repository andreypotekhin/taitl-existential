# T10262601 General On Rules Skipped by Event Dispatch

## Defect

General On handlers declare the common Event type. Concrete report selection included event families and Expression,
but omitted Event. Intent grouping likewise omitted the general family. General invariants/effects were skipped and
general intent restrictions could be bypassed. Access acceptance reproduced the failure; the same route affects all
built-in events. Direct On.handle calls were not affected.

## Correction and acceptance

ResolveSelectionInput now includes Event alongside Expression, using the configured naming mode. Intent grouping
includes the common family with the original payload/type candidates. EventField reuses ordered selections; general
and specific intents are merged back into shared/local declaration order. No synthetic Access/write/mutation event,
new registry, or extra entity recording is introduced. Existing missing-intent gating and conjunctive restrictions stay.

UserCanApplyGeneralEventRules.generalRulesAreNotSkippedT10262601 verifies general authorization, checks, effects,
identity folding, and selected bi-event subjects for 14 built-in report shapes under both naming/expansion settings.
The same class verifies parent/child/local intent order and effect-aware stopping. UserCanValidateAccessEvents covers
45 access/stage/enrollment/recovery scenarios. Root build (605 tests), consumer (seven tests), reactor, and
three-process performance comparisons passed. See the
[delivery plan](../planning/P10262601.Sprint09-access-event-acceptance.plan.md).
