### S03022601 Shortcut ContextBuilder.build to ConfigBuilder.build

On ConfigBuilder, we can build several contexts by successfully calling .context()
But, when we have a build() call in the end of call chain, it only builds the last context.
We want to refactor to: 
1) Create ConfigBuilder.build() (without parameters) to build all defined ContextBuilders and TransactionBuilder that weren't built so far
2) Refactor ContextBuilder.build() to be a shortcut to ConfigBuilder.build() (thus, building whole config) 
3) Guard against repeat calls to ContextBuilder.build()/ConfigBuilder.build() (only allow one time, e.g. in the end of configuration call chain)
4) Guard against ConfigBuilder.build() never called (e.g. by introducing 'check ' built boolean field in ConfigBuilder) and checking as part of FinalizeConfiguration
